# Movilidad-urbana-y-productividad-economica-en-ciudades-de-LATAM
El objetivo de este proyecto es entregar un reporte para entender cómo la movilidad urbana (niveles de congestión, tiempos de viaje, retrasos) se relaciona con la productividad económica (PIB per cápita, desempleo) en las principales ciudades latinoamericanas
# Herramientas
Python (pandas, numpy, seaborn, matplotlib), Notebook, Pensamiento programatico y critico, Analisis, visualización y limpieza de datos.

# Preguntas clave
- ¿Qué relación existe entre la movilidad urbana (congestión, tiempos de viaje) y la productividad económica (PIB per cápita)?
- ¿En qué ciudades invertir en infraestructura de transporte para aumentar la productividad y el bienestar de la población?
- ¿Qué ciudades de América Latina presentan alta congestión y baja productividad económica?

# Metodología
- Cargar, explorar y visualizar los datos.
- Explorar, limpiar y preparar los datos.
- Crear un dataset único y limpio a partir de las fuentes de infromación.
- Aplicar estandarización y validación de tipos de datos.
- Filtrar y enfocar el análisis en ciudades latinoamericanas.
- Calcular indicadores agregados (por ciudad–año).
- Realizar análisis exploratorios y visuales.
- Documentar todos los pasos en Jupyter Notebook.

# Conclusiones 
- A partir del gráfico no se observa una relación clara entre el PIB per cápita y el nivel de congestión. Ciudades con altos niveles de PIB pueden presentar tanto altos como bajos niveles de retraso, lo que sugiere que la congestión urbana depende de otros factores adicionales como la planificación urbana, el transporte público, la densidad poblacional o el uso del automóvil.
- Bogota y Lima muestran una combinación entre alta congestion y  baja productividad economica.
- Segun el grafico no necesariamente las ciudades con mayor PIB per cápita presentan más congestión, por ejemplo Montevideo es la ciudad con mayor PIB pero no presenta una gran congestión en comparación con ciudades como Lima y Sao Paulo que tienen menor PIB y mayor congestión.

# Recomendaciones
- Se recomienda priorizar ciudades como Bogotá y Lima para análisis más profundos e inversiones en infraestructura de transporte, ya que muestran una combinación alta de congestión y menor productividad económica relativa. Sería bueno incorporar variables adicionales como; densidad poblacional o cobertura de transporte público para realizar análisis estadísticos que permitan mejorar la correlación. En el plano economico las futuras inversiones deberían enfocarse por ejemplo en transporte público masivo y planes de movilidad, con el fin de reducir pérdidas de tiempo y mejorar la eficiencia económica urbana.
